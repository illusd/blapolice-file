# BalaPolice 巴拉國警察局

巴拉國警察局官方靜態網站（HTML / CSS / JS）。

- 風格對齊 [blagov.illusd.com](https://blagov.illusd.com/)
- 完整法律條文與處罰內容（含無期徒刑、再犯加重）
- 招募年齡：10 歲以上

## 頁面

| 檔案 | 說明 |
|------|------|
| `index.html` | 首頁 |
| `laws.html` | 法律全文（互動） |
| `penalties.html` | 處罰內容 |
| `laws-fetch.html` | 純文字完整法律＋處罰（無 CSS／按鈕） |

## 部署

靜態檔案，可直接部署至 Vercel（專案 `balapolice-1`）或任意靜態主機。
