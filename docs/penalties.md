## 重要刑罰原則

- **無期徒刑**：適用於故意殺人、放火致死、搶劫致死、受賄違背職務情節重大、攻擊關鍵基礎設施致死、報復證人致死等。
- **再犯**：多數刑事規定「五年內再犯加重其刑至二分之一」；交通與秩序罰鍰得加重至一倍半或二倍；常業犯得保安處分或撤銷資格。
- **少年**：未滿十四歲不罰；十四歲以上未滿十八歲得減輕，並依少年保護程序。

## 擴充處罰摘要

### 緊急狀態與災害應變法
| 罪名 | 主刑 |
|------|------|
| 拒不遵守疏散／警戒 | 六月以下有期徒刑、拘役或罰金 |
| 散布虛假緊急訊息 | 一年以下；致人死傷加重 1/2 |
| 五年內再犯 | 加重 1/2 |

### 網路安全與電腦犯罪防制法
| 罪名 | 主刑 |
|------|------|
| 無故入侵系統 | 一年以上三年以下 |
| 詐取帳密不法使用 | 六月以上五年以下 |
| 惡意程式供犯罪 | 一年以上七年以下 |
| 攻擊關鍵基礎設施 | 三年以上十年以下；致死得**無期徒刑** |
| 再犯／常業 | 加重 1/2 |

### 肅貪與公務廉潔法
| 罪名 | 主刑 |
|------|------|
| 受賄違背職務 | 七年以上；情節重大**無期徒刑** |
| 受賄不違背職務 | 三年以上十年以下 |
| 行賄 | 一年以上七年以下 |
| 警察／司法犯貪污 | 加重 1/2 並免職 |

### 證人與被害人保護法
| 罪名 | 主刑 |
|------|------|
| 報復證人／被害人 | 一年以上七年以下；致死**無期徒刑** |
| 公務員洩漏受保護人資訊 | 一年以上五年以下並懲戒 |
