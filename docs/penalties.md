## 巴拉國憲法（治安相關條款） {#pen-constitution}

### 1. 公務員故意違憲侵害人民權利

| 項目 | 內容 |
|------|------|
| 條文 | 第 16 條 |
| 主刑／主要處罰 | 懲戒（申誡、記過、減俸、停職、免職）；涉及犯罪者移送司法 |
| 附加／其他 | 被害人得依國家賠償請求金錢賠償 |
| 少年／兒童 | 不適用刑事，但公務員仍受懲戒 |

### 2. 公權力違法侵害致生損害

| 項目 | 內容 |
|------|------|
| 條文 | 第 17 條 |
| 主刑／主要處罰 | 國家賠償（金錢賠償或回復原狀） |
| 附加／其他 | 對有故意或重大過失之公務員得求償 |
| 少年／兒童 | 法定代理人得代為請求 |

### 3. 以不正方法取證作為有罪判決依據

| 項目 | 內容 |
|------|------|
| 條文 | 第 10 條 |
| 主刑／主要處罰 | 該證據應予排除；相關人員懲戒或刑事責任依其他法律 |
| 附加／其他 | 得聲請再審或非常救濟 |
| 少年／兒童 | 特別保護，審判以不公開為原則 |

| 附加／其他 | 對有故意或重大過失之警察得求償 |

### 2. 警察違法失職

| 項目 | 內容 |
|------|------|
| 條文 | 第 13 條 |
| 主刑／主要處罰 | 懲戒：申誡、記過、減俸、停職、免職 |
| 附加／其他 | 涉及犯罪者移送司法 |
| 少年／兒童 | 少年警察以告誡、限制勤務、終止任用為主 |

### 3. 警察收受賄賂

| 項目 | 內容 |
|------|------|
| 條文 | 第 14 條 |

| 附加／其他 | 賄賂及所得沒收 |
| 少年／兒童 | — |

### 4. 警察刑求、脅迫取供或故意為虛偽文書

|------|------|
| 條文 | 第 15 條 |

| 附加／其他 | 取得之證據排除 |
| 少年／兒童 | — |

### 5. 警察無故洩漏職務上秘密或個人資料

| 項目 | 內容 |
|------|------|
| 條文 | 第 16 條 |
| 主刑／主要處罰 | 依隱私法及刑法；得予停職或免職 |
| 附加／其他 | 民事損害賠償 |
| 少年／兒童 | — |

## 刑法 {#pen-criminal-code}

### 1. 殺人（一般）

| 項目 | 內容 |
|------|------|
| 條文 | 第 16 條 |

| 附加／其他 | 得褫奪公權；凶器沒收 |
| 少年／兒童 | 未滿十歲不罰；十至十四歲保護處分優先；十四至十八歲得減輕；未滿十八歲不得處無期徒刑，改處十五年以上二十年以下 |
